# Yap++ Studio

A customisation plugin for Yap++ by Dexterious: themes, clock, focus timer, achievements, Pixel Studio and more.

## Install

1. Open **Releases** on the right and pick a version.
2. Download `Yap++ Studio Installer vX.X.zip` and extract it.
3. Run the `.bat` inside and click **Install** (or **Reinstall** to replace an older version).

Every version has its own installer, so you can roll back by installing an older one.
