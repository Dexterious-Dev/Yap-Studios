How to install

  1. Make sure you have Yap++ installed.
  2. Download the .exe for the version you want and run it.
  3. Click Install. Yap++ restarts and Studio is in Settings.

The .zip is the same installer as a script, if you prefer: extract it and run the .bat.

Windows blocked it?

Windows is careful with new downloads. Right-click the file you downloaded, choose Properties, tick Unblock at the bottom, then OK, and run it again.

If you see "Windows protected your PC", click More info, then Run anyway.

Is it safe?

  • It copies one file into Yap++'s plugins folder. Nothing else changes.
  • No internet, no admin rights, nothing left running.
  • Never touches your password, login or messages.
  • Uninstall removes it completely.
