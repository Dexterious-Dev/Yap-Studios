Set up admin

The panel works through a GitHub key that can only touch this one repo. You make the key, this page locks it with a new random password, and only that password can unlock it again.

  1. Open GitHub: new fine-grained token (signed in as Dexterious-Dev).
  2. Name it anything. Pick an expiry (when it runs out, come back here).
  3. Repository access: Only select repositories → Yap-Studios.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Generate it and paste it below.

Your admin password. It is shown once and can't be recovered, so save it in a password manager now.
